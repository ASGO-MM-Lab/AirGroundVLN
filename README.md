## 💡 Introduction

<div align="center">
  <img src="assets/overview.png" alt="AirGroundVLN benchmark overview" width="100%"/>
</div>

**AirGroundVLN** is a large-scale benchmark for goal-oriented air-ground collaborative Vision-and-Language Navigation (VLN). The benchmark contains **10,281** navigation episodes, **955** target instances, and **19** diverse scenes for goal-oriented air-ground collaborative VLN. It supports evaluation across **aerial-visible/aerial-occluded** target conditions and seen/unseen environments. **AG-CoNAV** is provided as a trainable reference framework for this setting.

## 📦 Dataset

The [AirGroundVLN dataset](https://huggingface.co/datasets/Pppang/AirGroundVLN) provides simulation environments, goal-oriented navigation episodes, and aerial and ground agent trajectories.

### Dataset Download

To download the dataset locally, use the Hugging Face Hub CLI:

```bash
pip install -U huggingface_hub
hf download Pppang/AirGroundVLN --repo-type dataset --local-dir ./data/AirGroundVLN
```

### Dataset Structure

After extraction, the dataset directory is organized as follows:

```text
AirGroundVLN/
├── envs/
│   ├── BrushifyUrban/
│   ├── Chernobyl/
│   └── ...
├── trajectories/
│   ├── BrushifyUrban/
│   │   ├── BrushifyUrban__episode_0001/
│   │   │   ├── episode_metadata.json
│   │   │   ├── uav_trajectory.json
│   │   │   ├── ugv_trajectory.json
│   │   │   ├── UAV_log/
│   │   │   └── UGV_log/
│   │   ├── BrushifyUrban__episode_0002/
│   │   └── ...
│   ├── Chernobyl/
│   └── ...
├── scripts/
│   ├── capture_uav.py
│   ├── capture_ugv.py
│   ├── simulator_listener.py
│   └── settings.json
├── README.md
└── .gitattributes
```

| Directory | Description |
| --- | --- |
| `envs/` | Executable simulation environments |
| `trajectories/` | Episode annotations, navigation instructions, reference trajectories, and per-frame pose logs |
| `scripts/` | AirSim configuration and observation capture utilities |

**Trajectory Format**

Each episode directory under `trajectories/` contains the following files and subdirectories:

| File or Directory | Description |
| --- | --- |
| `episode_metadata.json` | Episode information, navigation instruction, and optional visibility or occlusion labels |
| `uav_trajectory.json` | Aerial reference trajectory |
| `ugv_trajectory.json` | Ground reference trajectory |
| `UAV_log/` | Per-frame aerial poses |
| `UGV_log/` | Per-frame ground poses |

### Training Data Preparation

AG-CoNav is trained using pre-collected UAV and UGV observations.

**Requirements**

The observation capture scripts require the AirSim Python client (`airsim`), NumPy (`numpy`), and OpenCV (`cv2`).

**Observation Pre-collection**

The training observations are generated by replaying the released UAV and UGV pose logs in AirSim.

**1. Start the simulator listener.**

Open a terminal in the downloaded AirGroundVLN dataset directory and run:

```bash
python scripts/simulator_listener.py --port 56379 --settings-json scripts/settings.json --envs-root ./envs
```

The listener uses port `56379` to receive scene switch requests. AirSim uses its own RPC port, set by `ApiServerPort` in `scripts/settings.json` (`41561` in the supplied configuration). Keep the listener running during data collection.

**2. Capture UAV and UGV observations.**

Open a second terminal in the same directory and run ( To save observations directly in the episode directories alongside the pose logs, set `--output-root ./trajectories`.):

```bash
python scripts/capture_uav.py --dataset-root ./trajectories --output-root ./observations --simulator-port 56379
python scripts/capture_ugv.py --dataset-root ./trajectories --output-root ./observations --simulator-port 56379
```

Set `--simulator-port` to the listener's `--port` from step 1. The capture scripts connect to the AirSim RPC port automatically after the listener starts the scene.

Each script processes all extracted trajectory environments sequentially. Add `--env BrushifyUrban` to capture only that environment. To capture a single episode, also add `--episode BrushifyUrban__episode_0001`.

**Observation Data Format**

After both capture scripts finish, each processed episode contains five observation directories:

```text
observations/
└── BrushifyUrban/
    └── BrushifyUrban__episode_0001/
        ├── bevcamera/
        ├── bevcamera_depth/
        ├── bevcamera_depth_valid/
        ├── frontcamera/
        └── frontcamera_depth/
```

| Directory | Description |
| --- | --- |
| `bevcamera/` | UAV bird's-eye-view RGB images |
| `bevcamera_depth/` | UAV bird's-eye-view depth images |
| `bevcamera_depth_valid/` | UAV BEV depth-validity masks |
| `frontcamera/` | UGV forward-facing RGB images |
| `frontcamera_depth/` | UGV forward-facing depth images |
